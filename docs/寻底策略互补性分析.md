# 寻底类策略互补性分析

> 状态：2026-08-19 全组快照。覆盖 `scripts/` 下 9 个寻底类脚本；其余脚本（`find-leader` 龙头、`find-wave` 波浪、`find-jerry` 某队、`scalper` 抢尾盘）为寻底链条的相邻环节，不在此列。

## 一、全景：9 个脚本在股价循环中的位置

| 脚本 | 循环阶段 | 核心信号 | 周期 | 前复权 | 回测 |
|---|---|---|---|---|---|
| `find-bottom` | **左侧超跌**（最左） | 收 < DEMA20 进买入区，RSI14 上穿30 卖出 | 日线 | ✅ | ✅ vs 持有 |
| `find-macd-mingc` | **见底预警** | 30m 底背离（价新低+DIFF 抬高）+ 5m 零轴金叉 | 5m/30m | ✅ | ❌ 延后 |
| `find-reversal` | **底部形态确认** | 60日回撤>40% + 锤头 + 假阴 + 高换手 + 二次探底不破 + 突破 | 日线 | ✅ (0.42.1 起) | ✅ 滑窗+按底去重 |
| `find-terrain` | **底部形态识别** | GMMA 地貌「谷底收敛」「向上转折带」，波束扫描九分类 | 日线 | ✅ | ✅ +OOS 标定 |
| `find-finish-eating` | **吸筹结束→启动**（最靠右确认） | 60日平台 + 地量 + 换手萎缩 + 筹码集中 + 户数减少 + 放量破颈线 | 日线 | ✅ | ✅ 滑窗 |
| `find-trivol` | **放量启动 + 回踩** | 三倍量锚 → 红线，金叉/回调低吸/突破三买点 | 日线 | ✅ | ✅ 规则出场 |
| `find-retrace` | **启动后回踩低吸** | 昨涨停今低开 + 距一年底 ≤10% | 日线 | ✅ | ✅ 滑窗 |
| `find-macd-weekdc` | **洗盘后主升确认** | 周线 MACD 建仓→死叉→二次金叉 + 放量 + 站均线 | 周线 | ✅ | ✅ 周线滑窗 |
| `find-byslope` | **金叉动能分级** | MA5 上穿 MA20 + 归一化斜率分桶（标定工具+今日清单） | 日线 | ✅ | ✅ 分桶 |

按循环线排开：

```
左侧接飞刀        见底预警            底部形态确认        吸筹结束/启动        启动后回踩         主升/动能确认
find-bottom ──→ find-macd-mingc ──→ find-reversal ──→ find-finish-eating ──→ find-retrace ──→ find-macd-weekdc
                                        ├ find-terrain       ├ find-trivol(金叉/突破)  └ find-trivol(回调低吸)   └ find-byslope
                                        └ (谷底收敛)          └ (同为启动,确认强度弱一档)
```

**核心结论**：这 9 个脚本不是重复实现，而是把同一条寻底路径切成 5-6 个不同阶段——左侧介入（bottom）、预警（mingc）、形态确认（reversal/terrain）、突破启动（finish-eating/trivol）、回踩低吸（retrace/trivol）、趋势确认（weekdc/byslope）。互补性建立在这个阶段差上。

## 二、三层互补关系

### 1. 周期互补 —— 同一思路的多周期实现

`find-macd-weekdc` 与 `find-macd-mingc` 底层是**同一套 MACD(12,26,9) 金叉**，但：

- `mingc` 在 5m/30m 上做「背离(左)+零轴金叉(右)」——日内快进快出，金叉 2 小时新鲜度；
- `weekdc` 在周线（日线重采样）上做「两次金叉夹死叉」——中线波段，4 周新鲜度，且多了放量/站均线确认。

组合价值：`weekdc` 周线定方向（大周期确认洗盘结束），`mingc` 日内扣扳机（小周期找买卖点）——大周期选股 + 小周期择时，经典周期共振，互补而非重复。

### 2. 信号源互补 —— 独立信号降低同源误报

| 信号类型 | 脚本 | 代表指标 |
|---|---|---|
| 均值回归 | `bottom` | DEMA/RSI |
| 量价 | `trivol`、`finish-eating` | 三倍量/地量/放量破位 |
| 形态结构 | `reversal`、`terrain`、`finish-eating` | 锤头/谷底/GMMA 地貌/颈线平台 |
| 指标动量 | `mingc`/`weekdc`/`byslope` | MACD 背离金叉、均线斜率 |

`find-finish-eating` 独占**筹码/情绪维度**（换手萎缩、90% 成本集中度、股东户数减少、大盘跌时抗跌），是全组唯一的资金筹码确认。

### 3. 验证能力互补 —— 8 个有回测的当"标尺"

- `find-terrain` 回测最全（+5/20/65 前瞻 + 3×3 阈值 OOS 标定），且诚实暴露问题：OOS 胜率 46.4% < IS 58.5%，「下降谷底收敛」+65 日超额 +3.1pp 靠少数大赢家撑均值——收益右偏，不能重仓。
- `find-bottom` 有 vs 买入持有的逐股回测；`find-trivol` 有规则出场回测 + 250 日位置分组（验证"低位优先"）；`find-byslope` 有斜率分桶 + 前瞻收益标定（脚本注释明确要求"由评估结果定开仓阈值"）。
- **0.42.1 补齐滑窗回测**：`retrace`/`reversal`/`finish-eating` 复用各自 `screen_stock` 逐日滑窗（reversal 按底部日去重、finish-eating 跳过无历史的 F10），`weekdc` 逐周截断周线重跑 `detect_double_cross`；四者共用 `common.forward_ret`/`report_events`（+5/20/65 前瞻 + MAE）。实测 zxg 池：retrace 1 事件、finish-eating 3 事件、weekdc 96 事件（+20 日 +4.5%，胜率 58%）。
- **仅剩 `mingc` 无回测**：5m/30m 分钟级滑窗重算成本高、freshness 去重语义复杂，延后。原"finish-eating 是全组验证盲区"的结论已解决——它是 0.42.1 首个补上回测的。

## 三、组合用法

1. **漏斗叠加三重确认**：`terrain(谷底收敛)` → `finish-eating(吸筹结束)` → `trivol(三倍量买点)`。三层信号源互异（形态/筹码/量价），交集标的 = 底部+资金+买点全确认。`find-terrain` 自述"反转筛选漏斗"，本身按此思路设计。
2. **周期共振**：`weekdc` 周线二次金叉选方向池 → `mingc` 日内背离+金叉找入场 → `trivol` 红线止损。
3. **错误配对互证**：`bottom` 报买入区（接飞刀风险）时，用 `mingc` 的背离"动能衰竭"过滤——等衰竭确认再买，把无止损的均值回归变成有依据的左侧介入。
4. **回踩接力**：`reversal`/`terrain` 确认底部后，`retrace` 专门抓"涨停启动→回踩不破底"的二次低吸机会。

## 四、口径一致性现状（0.42.1 起）

修复记录：

- **前复权统一**：`find-reversal` 接入 `common.apply_qfq`/`batch_fetch_adjust`，全组 9 个脚本前复权口径一致（此前它是唯一不复权脚本，除权缺口会造出假回撤/假锤头/假底部）。实测 sh600018 因窗口内近期除权，回撤 12.9%→15.3%。
- **ST 排除统一**：`common.is_st_name` 单一来源（命中 `*ST`/`ST` 名称）；`bottom`/`retrace`/`reversal`/`finish-eating` 标的池统一剔除，`trivol` 的 `is_excluded`/`limit_ratio` 改调共享 helper。北交所/科创板按用户决策**保留为各策略设计选择**（如北交所 30% 涨停、688 高波动），不统一排除。
- **大盘择时**：`common.market_regime` 查 `k_sh000001_1d`（收 > MA20 且近 20 日涨跌 > 0 = 多头），9 个脚本统一在 stderr 打印 `[大盘] 上证 XXXX MA20↑ 近20日+Y% 多头/空头` 标注；加 `--market-bull` 可选硬过滤（默认关，空头时跳过筛选）。
- **回测补齐**：8/9 有回测（见第二节 3），共享 `common.forward_ret`/`report_events`。

顺带修复：`common.fetch_kline`/`sector_momentum` 的 `len(TaosResult)` 崩溃（taosws 新库的 query 返回不可 `len()`，改用 `list()`），`fetch_kline` 由此对 mingc 等调用方恢复可用。

仍待对齐：

1. **无统一出场纪律**：`bottom` 明确无止损；`trivol` 用红线/量低止损；其余默认持有。横向比较胜率时口径不齐。
2. **`mingc` 回测延后**：分钟级滑窗成本高，见第二节 3。
3. **大盘硬过滤非默认**：`--market-bull` 默认关（底部反转常发生在指数尚弱时，硬切会漏掉领先反弹的底部股），需自动化场景显式开启。

## 五、一句话总结

> 这 9 个脚本把"寻底"拆成**左侧接飞刀 → 背离预警 → 形态确认 → 突破启动 → 回踩低吸 → 主升确认**六个连续阶段，周期从日内到周线、信号从量价到筹码全覆盖，组合起来是一条完整漏斗；0.42.1 已统一复权与 ST 排除、接入大盘择时、补齐 4 个滑窗回测（8/9 有回测），仅剩 `mingc` 分钟级回测延后。
